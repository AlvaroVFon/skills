# 01 — Profile Dimensions

Each dimension below becomes a profile field. Prefer the learner's own words; map to the
buckets only as a convenience. Any dimension the learner cannot answer goes to **Open Questions**.

## Identity

A stable handle for the profile (`learner`). Not a full real name unless offered.

## Goals

Short-term (weeks) and long-term (months) outcomes, plus the `Target level`. Weekly time
available belongs to constraints, not goals. Unnamed goals block `mentor`; if the learner has
none, record "exploration" as the goal.

## Preferences

| Dimension    | Buckets                                             | Signal to watch                    |
| ------------ | --------------------------------------------------- | ---------------------------------- |
| Modality     | visual, auditory, reading/writing, kinesthetic, mix | what they ask for unprompted       |
| Structure    | sequential/global, examples-first/theory-first      | how they react to intro vs example |
| Pacing       | fast, steady, deliberate                            | frustration vs boredom             |
| Feedback     | immediate/delayed, gentle/direct, frequent/sparse   | when corrections land              |
| Session size | minutes or exercises                                | attention drop-off                 |

Preferences can evolve; update them from evidence rather than treating them as fixed labels.

## Motivation & Constraints

Drivers (why), time budget, and hard constraints: accessibility needs, language, available
tools, environment, or schedule. Constraints are `[confirmed]` and must never be violated by
`mentor`; they are the highest-priority fields.

## Meta-cognition

Self-regulation (planning, monitoring, help-seeking) and study habits. These are often
`[inferred]` from observed behavior before the learner confirms them. Record strengths and gaps
separately so `mentor` can target the zone of proximal development.

## Domains

One section per domain. Prior knowledge is a coarse level plus concrete strengths and gaps.
Keep evidence notes beside the field they explain, not in a separate log.

## Probing Guidance

- Ask open questions first, bucket afterward.
- One theme per turn; stop the block when the learner disengages.
- Never guess an answer to fill a field; put it in Open Questions instead.
- Mark distress or sensitive disclosures only with consent.
